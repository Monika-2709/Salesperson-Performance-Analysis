📊 Salesperson Performance Analysis

A data analytics project focused on evaluating and comparing salesperson performance using Sales, Profit, Growth, Average Order Value (AOV), and Territory Analysis.

🎯 Objective

Evaluate salesperson performance fairly instead of relying only on revenue.

🛠️ Tools & Technologies
Power BI – Dashboard and interactive visualizations
SQL – KPI analysis and ranking
Excel – Data analysis and reporting
Python & Pandas – Data preparation and validation
📌 Key KPIs
Total Sales
Total Profit
Profit Margin
Total Orders
Average Order Value
Year-over-Year Sales Growth
Territory Performance
Overall Performance Score
🏆 Performance Scoring

A weighted scoring system was used to provide a balanced evaluation:

KPI	Weight
Sales	30%
Profit	30%
Growth	20%
Average Order Value	20%

Each KPI is normalized before calculating the final performance score.

📊 Power BI Dashboard

The dashboard includes:

KPI cards
Salesperson sales ranking
Profit comparison
Sales growth analysis
Territory-wise sales
Sales vs Profit scatter plot
Monthly sales trend
Salesperson performance ranking
Interactive slicers for Year, Territory, Category, and Salesperson
💡 Key Insight

Revenue alone is not sufficient to evaluate salesperson performance.

A salesperson may generate high sales but have low profitability because of discounts or product mix. Therefore, combining sales, profit, growth, and AOV provides a more balanced evaluation.

Territory differences are also considered because territories can have different market sizes and sales opportunities.
