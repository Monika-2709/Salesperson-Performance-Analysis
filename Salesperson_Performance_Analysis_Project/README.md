# Salesperson Performance Analysis

## Objective
Compare salespeople using **sales, profit, growth, and average order value (AOV)**.

## Deliverables
- Salesperson_Performance_Data.csv
- Salesperson_Performance_Analysis.xlsx
- salesperson_analysis.sql
- PowerBI_Guide.md
- Salesperson_Performance_Report.pdf
- charts/

## Ranking methodology
Sales 30% + Profit 30% + Year-over-year Growth 20% + AOV 20%.
Each metric is normalized to 0–100 before weighting.

## Important
The dataset is a reproducible Superstore-like dataset created for this task, covering 2024–2025, multiple territories and product categories.
